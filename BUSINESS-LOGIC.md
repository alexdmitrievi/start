## FAQ STRUCTURE — Full Copy

**Section label:** "Часто задают"

**FAQ 1:**
```
Q: "У меня долги / исполнительное производство. Откажут?"
A: "Нет автоматического отказа. Долги — это фактор, который
    учитывается при оценке, а не запрет. У меня самого было
    исполнительное производство на 1,4 млн рублей — и я получил
    социальный контракт.
    
    Важнее то, как оформлена заявка. Именно здесь я помогаю:
    подготовить документы так, чтобы сложности не стали основанием
    для отказа."
```

**FAQ 2:**
```
Q: "Я работаю / моя ситуация нестандартная — мне это не подходит?"
A: "Программа распространяется не только на безработных.
    Трудоустроенные с низким доходом, самозанятые, ИП —
    все эти категории могут подать заявку.
    
    Пройдите тест — это быстрее, чем читать официальные
    описания программы."
```

**FAQ 3:**
```
Q: "Зачем платить за консультацию — если это государственная программа?"
A: "Программа действительно государственная и бесплатная.
    Консультация — это не доступ к программе. Это ваш шанс
    подать заявку правильно с первого раза.
    
    Ошибки в документах, неправильный выбор направления,
    упущенные региональные требования — всё это ведёт к отказу,
    после которого нужно ждать и подавать снова.
    
    Моя работа — чтобы этого не случилось."
```

**FAQ 4:**
```
Q: "Гарантируете ли вы одобрение?"
A: "Нет — и это важно сказать честно. Решение принимает
    государственная комиссия, не я.
    
    Я гарантирую: профессиональный анализ вашей ситуации,
    правильно оформленные документы, стратегию, основанную
    на реальной практике, и честный ответ на вопрос
    'есть ли смысл подавать именно вам'."
```

**FAQ 5:**
```
Q: "Сколько времени занимает рассмотрение?"
A: "Официально — от 10 до 30 рабочих дней в зависимости от региона.
    Фактически — может растянуться. Я отслеживаю статус заявки
    в рамках полного сопровождения и напоминаю комиссии о себе,
    когда это уместно."
```

**FAQ 6:**
```
Q: "Как тратятся деньги? Придётся отчитываться?"
A: "Да — деньги целевые, расходы нужно документировать.
    Это не сложнее, чем вести простую таблицу с чеками.
    Я объясняю требования заранее и помогаю выстроить
    систему учёта на консультации."
```

**FAQ 7:**
```
Q: "Мне раньше отказали. Можно подать снова?"
A: "Да. Повторная подача разрешена — при условии изменения
    обстоятельств или исправления причин отказа.
    
    Самая частая ситуация: первая подача — без консультации,
    с ошибками в оформлении. Вторая — правильная.
    Именно с повторными заявками я работаю особенно часто."
```

## CTA STRATEGY — Section-by-Section

**CTA Principle:**
- Every section has ONE primary CTA and one secondary (max)
- Primary CTA = always move down the funnel
- Secondary CTA = softer alternative (Telegram, result, learn more)
- Never two equally weighted CTAs on the same screen

**SCARCITY MESSAGING (only factual, no fake urgency):**

```
VALID SCARCITY A:
  "Региональные бюджеты на социальные контракты ограничены
   и расходуются в течение финансового года"
  ← Factual. This is true of all government budget programs.

VALID SCARCITY B:
  "В [регион] прием заявок ведётся до [date/period]"
  ← Only show when you have actual regional data

INVALID (forbidden):
  "Осталось 3 места" ← fake
  "Только сегодня" ← fake  
  "Предложение заканчивается через 10:00:00" ← fake
```

**TRANSPARENCY SIGNALS:**

```
SIGNAL 1 — About the test:

## CONVERSION FLOW — Full User Journey Diagram

```
[ENTRY POINTS]
  ↓ Organic search → Hero section
  ↓ Social / referral → Hero section  
  ↓ Telegram direct → Contact step (skip test)
  ↓ Return visitor → Direct to test entry

[AWARENESS → INTEREST]
  Hero → Pain Mirror (myth-busting)
  → Personal Story (trust)
  → How It Works (clarity)
  → Test Entry (decision point A)

[DECISION POINT A: Test or Not]
  Path A: Takes test → Full 8-step flow
  Path B: Doesn't take test → Scroll continues → sees cases + FAQ → test entry again

[TEST FLOW]
  Step 1 → Step 2 → Step 3 → Step 4 → Step 5 →
  Step 6 → Step 7 → Step 8 → Score Calculation →
  Result Screen (A/B/C/D) → Contact Form

[RESULT SCREEN BRANCHING]
  HIGH (75-92):    "Book consultation" primary path
  MEDIUM (45-74):  "Telegram discussion" primary path
  LOW (15-44):     "Free 15-min express" primary path
  COMPLEX:         "Telegram — personal note" primary path

[CONTACT STEP]
  Submit → Telegram pre-fill → Manual follow-up
